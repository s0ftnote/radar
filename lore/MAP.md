## Project knowledge

- [Radar 设计系统](../DESIGN.md) — 新增或评审 Web 界面时打开；这里记录已交付的视觉令牌、排版边界、响应式拓扑、组件状态与动效规则。 `active`
- [多个 Brief 共享来源内容但不共享判断](../docs/adr/0007-briefs-share-sources-not-judgments.md) — 修改来源复用、Agent 判断、Signal 出处链或 Brief 导出边界时打开；#40 已把 Radar Project 收缩为 Radar Brief，旧的浏览器级验证结论需重新验证。 `needs-review`
- [Radar 不做 AI，也不拥有沉淀](../docs/adr/0009-radar-does-no-ai-and-owns-no-knowledge.md) — 讨论 Radar 是否该调模型、是否该存长期沉淀，或划分 Radar 与用户 Agent 职责时打开；本决定取代原 ADR 0001–0006。 `active`
- [AI 边界会拖走它维护的领域对象](./ai-boundary-drags-domain-objects.md) — 增删领域对象、设计 Radar Skill 操作面，或想给本体加一个「以后再说」的推理接口时打开；判定规则是问「谁做它的合并、修订、汇总、排序」。 `active` · graduation `deferred`
- [Walking skeleton 复现手册](../docs/contributing/walking-skeleton.md) — 从干净检出验收唯一启动路径、公开 Web 全链、离线包检查或重启恢复时打开。 `active`
- [地图关闭时的决策流失](map-closure-decision-loss.md) — 关闭、重画或标「取代」任何 wayfinder 地图前打开，往旧票上补标替代关系时也打开；说明评论里的决议为何会随关图流失、关图前的逐票对照规则，以及四条已验证的旧票标注记法（不改写正文、恢复标注放在盖过它的票上、矛盾两侧都标、失效链接用独立评论更正）。 `active` · graduation: deferred
