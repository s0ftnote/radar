01 / Definition

自动沉淀，主动创造，按需输出

Report 仍然重要，但不再是产品的唯一中心。真正可复利的资产是用户自己的情报库、关系与 Idea。

Core job

把“我想持续知道什么”变成一个会积累、会关联、能再利用的私有情报空间

用户配置自然语言目标后，Radar 持续采集和匹配。通过判断的内容成为情报条目，不因当天没有查看而消失。

First user

先服务单个内容经营者

第一位用户仍是项目所有者本人；先把完整主循环做成可以长期使用的本地产品。

Product identity

通用个人情报图谱

Demand Radar 是首个模板。热点、技术趋势和其他方向以后复用同一套沉淀、关联与输出链路。

Automation

Report 自动化是可选项

用户可手动勾选和组合，也可保存输出方案后定时生成；Radar 不代替用户自动发布社交内容。

Ownership

开源、本地优先，用户掌管实例

用户从 GitHub 获取并在自己的设备或自托管环境运行 Radar；MVP 不需要 Radar 账号，数据、资产与来源凭据留在用户控制的环境中。

03 / Knowledge

图谱不是装饰，而是用户思考和创造的工作台

自动图谱负责看见真实关系，手工画布负责嫁接新的关系。两者共用同一份情报库，不是两套数据。

局部图谱示意证据关系 · Radar 建议 · 用户关系
情报库
一个 Radar Project 长期沉淀的私有知识空间，不是当天看完即消失的 Feed。
情报条目
由一个或多个 Signal 支撑、以判断而非文章为身份的长期资产，独立于任何 Report 存在。
证据与修订
来源内容支撑或反驳判断；新证据形成可追溯修订，当前结论不会覆盖历史结论。
关联
节点之间带含义的连接；来源可能是证据、Radar 建议或用户手工嫁接。
Idea
用户通过选择和连接情报条目形成的个人假设、角度或内容主张。
Report
从选定条目、关联与 Idea 生成的阶段性结果，是输出而不是长期存储单元。
平台物料包
同一 Report 派生的平台稿、可再渲染母版、PNG 预览、平台衍生图、来源与能力快照。
04 / Surfaces

四个产品表面，各自只解决一种任务

如果把沉淀、图谱、手工组合和输出全部塞进一张图，界面会很生动，但无法处理真实数量的信息。

01 · Dashboard

沉淀面板

查看最近新增、尚未处理、持续变化和需要判断的条目；支持列表、搜索和筛选。

02 · Graph

自动关系图

展示真实链接、Radar 建议和局部关系，用于发现结构和进入某个节点。

03 · Canvas

手工 Idea 画布

用户拖入节点、分组、标注和嫁接新关系，形成自己的观点或内容系列。

04 · Builder

Report 与物料生成器

选择一组节点、关系和 Idea，一次生成一个或多个平台物料包。

Prior art

图谱负责看见，画布负责构造

参考 Obsidian Graph View 与 Canvas 的分工，但节点首先来自 Radar 的采集与判断链路。

05 / Automation

始终自动的是准备，用户可选自动的是输出

这样既服务想省事的人，也保留给愿意探索和组合的用户足够控制权。

Always on

Radar 持续完成

  • 从 Source Network 增量采集并隔离来源失败
  • 按 Radar Brief 匹配、判断和形成情报条目
  • 发现关系、更新历史变化并提出关联建议
  • 保存证据、来源和可重新渲染的结构
User controlled

用户决定是否自动

  • 手动：勾选节点、关系或 Idea 后立即生成
  • 定时：保存输出方案，按频率生成并发送
  • 条件触发：待手动与定时语义明确后再决定
  • 发布：始终由用户审核并操作，MVP 不代发
06 / Outputs

一个 Report，可以长成多套平台物料

平台不是文件格式。PNG 是便于查看和下载的交付预览，不是跨平台唯一发布格式；每个目标按自己的能力生成衍生文件。

发布目标首批物料边界
小红书标题与正文、封面和图文卡母版、PNG 预览、JPEG 备用图、来源普通笔记的公开一手规格不足，必须用真实账号验收。
X单条或连续帖平台稿、每帖 1–4 张 PNG/JPEG、来源链接标准文案按 280 字符准备；长文能力按账号区分，图片单张不超过 5 MB。
Threads单条或连续帖平台稿、PNG/JPEG 轮播、来源清单普通文案按 500 字符准备；API 轮播最多 20 个媒体项，长文能力另行判断。
视频制作准备包封面 PNG、分镜 PNG、脚本初步 Idea、镜头清单、引用素材没有最终视频文件就不是可直接发布的视频物料；MVP 不渲染 MP4。
HTML网页、图谱快照 PNG、条目卡片 PNG、可点击证据页面可浏览和打印，但不是正式网站托管产品。
One source of truth

同一份证据，多种平台适配

用户只组合一次情报和 Idea；平台物料包共享判断与来源，不分别从 Prompt 重新编一遍事实。

Regeneration

交付预览，内部保留结构

Radar 保存卡片文字、图表配置、节点关系、模板和证据。观点变化后可重新渲染，不把 PNG 当唯一真相。

Pack anatomy

平台稿 → 可再渲染母版 → 平台衍生文件 → 来源 → 能力快照

来源信息不混进发布文案；账号和 API 能力也不写死在模板里。详细结论见首批平台物料包能力研究。
