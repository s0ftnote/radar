# 连接器同步来源与受管镜像，不共同拥有 Radar 对象

Radar 与外部知识库分层拥有对象：外部系统拥有原始页面、文件或数据库记录，Radar 拥有 Project、情报条目、关系、Idea、Report 及其修订历史，知识库连接器只维护来源追踪、连接器映射和同步观察。连接器把采集与发布建模为分别授权的方向，默认只采集；外部来源变化形成来源版本并触发重新判断，发布结果则是带 Radar 基线、镜像管理区和外部自有区的外部镜像。外部修改不能静默改写 Radar：来源修改触发重新判断，镜像管理区修改形成回流修订建议，基线不明或双方同时修改时进入镜像分叉；不采用最后写入者胜出或自动语义合并。

外部对象身份优先使用连接器实例与稳定外部 ID，路径和标题只是可变属性；无稳定 ID 且无法证明连续性时进入外部身份待确认，不以相似内容自动合并。通知只唤醒同步，连接器通过游标、授权范围快照和幂等对账恢复重复、乱序或遗漏变化，并用同步水位表达已确认的完整范围。外部对象进入垃圾箱、移出范围、失权、永久删除或原因未知只改变外部可用性，不级联删除既有 Radar 历史；暂停、断开和清除连接数据是不同动作。来源允许部分取得，但必须逐项披露正文、附件和嵌入内容状态，只有实际取得并可定位的内容才能支撑证据或 Report 引用。
