# 条件生成计划分离检测、生成与通知

条件生成计划持续摄取变化，但只在相对自身基线出现可检查的材料性变化时生成新的 Report；候选检测、去重与聚合、Report 生成和通知投递分别保存状态。这样可以在冷却或静默时段继续吸收证据、只让成功的 Report 推进基线，并避免把原始来源事件、重复内容或通知失败误当成新的 Report。

## Consequences

- 条件属于生成计划，不形成独立的 Report 类型；日历和条件是互斥的主触发方式。
- 每个计划独立保存版本化条件、比较基线、待处理变化和运行历史；其他计划或手动 Report 不改变它。
- 被去重、聚合、等待、冷却或静默处理的候选保留原因并可检查，未经用户确认的反馈不静默改写条件。
- Report 成功后即可推进基线；平台物料包或通知可独立失败和重试。
