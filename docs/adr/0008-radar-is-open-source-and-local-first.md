# Radar 采用开源、本地优先的单用户实例

Radar MVP 不以托管账号为产品入口，而由用户从开源仓库在自己控制的设备或自托管环境中运行；默认单用户、本地数据、本地资产且无 Radar 产品登录。这样让情报库、来源凭据与长期运行权掌握在用户手中，同时保留未来将实例部署到远程环境的可能。

## Consequences

- 默认 Web 界面只对本机开放，不实现账号、租户或多人权限；用户主动暴露到远程网络时，部署者必须另行启用访问控制。
- 外部来源仍可要求 OAuth、API token、Cookie 或数据库凭据；这些属于来源授权，保存在用户控制的本地 secret store，不进入领域数据或完整导出。
- 后台采集、定时计划、渲染和 Agent 操作由本机或用户自托管的进程执行，并继承明确的本机与来源权限。
- 完整导出仍然是正式能力，用于跨实例迁移、备份和脱离运行环境阅读，而不是从 Radar 云端“取回”用户数据。
- 官方托管、多用户协作、账号体系与付费服务若未来出现，作为独立部署模式设计，不能反向成为本地 MVP 的前置条件。
