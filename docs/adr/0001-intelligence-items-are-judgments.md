# 情报条目以判断而非来源内容为身份

Radar 将情报条目定义为由一个或多个 Signal 支撑、可以持续修订的长期判断，而不是文章、帖子或一次抓取结果。来源内容作为证据保留，临时 Signal 可以淘汰；这样既避免情报库退化为资讯 Feed，也让同一判断能够聚合多来源、保留演化历史并被关联、组合和复用。

## Consequences

- Radar 自动建议合并，但用户可以选择合并判断、保持独立并关联、标记重复或暂不处理。
- 情报条目保持稳定身份；新证据形成可追溯修订，不覆盖旧结论。
- 忽略不等于不感兴趣，删除默认可恢复，永久删除必须由用户明确触发。
- 完整导出交付一个包含结构化数据、可读内容和资产的 ZIP；结构数据覆盖 Brief、条目、Signal、证据、修订、关联、Idea、Report、平台物料包与反馈。
